# LOGO 与上架素材

## 1. LOGO 设计说明

**构成**：一台圆润的卡通小电视（机身 + 屏幕 + 两个旋钮 + 喇叭格栅 + 两只小脚），
屏幕里装着一颗有表情的番茄（红色果身 + 绿色花萼 + 果蒂 + 高光 + 腮红 + 微笑）。

**设计意图**
- 一眼读两层含义：外框 = 电视（视频/媒体），内部 = 番茄（Tomato 品牌色与造型）。
- 卡通化处理：统一深棕色描边（`#2A1C17`）、圆角、柔和投影，符合"可爱、亲和"的诉求。
- 小尺寸可读：所有关键元素都用 30px（1024 基准）以上的粗描边，缩到 48px 仍能辨认
  "电视 + 番茄"的轮廓；面部细节在小尺寸自然退化为一个红点，不会糊成一团。
- 颜色：番茄红 `#E54835`（= 应用主题品牌色）、叶绿 `#4CAF50`、机身暖白 `#FFFDFA`、
  背景暖渐变 `#FFFBF8 → #FBE9E5`，与应用内设计 Token 完全一致。

**留白与安全区**
- 平面图标（`logo_*.png`）：画面内容约占画布 73%，四周留白充足，平台裁圆角/圆形都不会切到主体。
- 鸿蒙分层图标：前景内容缩到画布 66%（`padding=0.66`），落在分层图标安全区内。

**矢量源**：`design/logo/logo.svg`（1024 viewBox），与 PNG 使用同一套几何参数，
需要改色/改比例时可直接编辑 SVG，或修改 `scripts/design/gen_logo.py` 后重新生成。

### 3.4 隐私政策要点（可直接复用）

> TomatoTV 是一款本地与网络文件管理器。应用不收集、不上传任何个人数据；
> 存储来源配置保存在应用私有目录，密码通过系统安全存储（Asset Store / HUKS）加密保存；
> 网络访问仅用于连接用户自己配置的 WebDAV / SMB / FTP 服务器；
> 歌词查询（LRCLIB）只发送歌曲标题与艺术家名称，不发送文件路径或凭据；
> 缓存文件仅写入应用私有缓存目录，可在「设置 → 缓存」中一键清理。

## 4. 重新生成 / 替换 LOGO

```bash
python scripts/design/gen_logo.py --verify     # 生成全部尺寸并打印字符画自检
```

如需改配色，改脚本顶部的 `TOMATO / LEAF / TV_BODY / OUTLINE / BG_*` 常量；
改造型改 `# ---------------- 几何（1024 基准） ----------------` 这一段。
生成后记得同步三处：

1. `AppScope/resources/base/media/app_icon.png` ← `logo_1024.png`
2. `entry/src/main/resources/base/media/app_icon.png` ← `logo_216.png`
3. `entry/src/main/resources/base/media/icon_foreground.png`、`icon_background.png` ← `layered/*`
